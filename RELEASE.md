# Permanent release rules

Keep the manifest URL fixed across all versions:
https://raw.githubusercontent.com/antiochusblack/dungeon-crawler-carl-foundry/main/system.json

For version X.Y.Z, set version to X.Y.Z and download to:
https://github.com/antiochusblack/dungeon-crawler-carl-foundry/releases/download/vX.Y.Z/dungeon-crawler-carl-X.Y.Z.zip

Preserve manifest and download whenever editing or regenerating system.json. Build the package from the current source with the identical updated system.json included. Name the ZIP dungeon-crawler-carl-X.Y.Z.zip and attach it to GitHub Release vX.Y.Z. Never use GitHub's autogenerated Source code.zip.

Before publishing, validate JSON, compare the source and packaged manifests, and confirm version, release tag, download URL and asset filename match. Verify that every declared script and style is packaged. Publish the matching asset before updating the stable main manifest to advertise it. Do not advertise an unreleased download URL from main while a release is still being prepared.
